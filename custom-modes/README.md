# Your lyrics modes

Every `.js` file in this folder is a lyrics mode Oley loads for you. It shows up in Settings → Lyrics modes with a "Yours" badge.

- Ask your AI (like Claude) to make one: "Make a new Oley lyrics mode in custom-modes where …".
- Or start from `_example.js`: copy it to a new name without the `_`.
- The full guide is `MAKING-MODES.md` in the Oley folder (and on the GitHub page).

Where this folder is: next to `Oley.pyw` if you run Oley from its source folder; `%LOCALAPPDATA%\Oley\custom-modes` if you installed it with the installer. **Settings → Open custom modes folder** always opens the right one.

Files starting with `_` are ignored. A picture named after the mode (`my-mode.jpg` or `.png`, 16:9) becomes its thumbnail.
